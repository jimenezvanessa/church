# 🎨 UI/UX Preference Guide

## Church Lyrics Auto-Slide Generator

---

## 🌟 Design Vision

The interface should feel **clean, calm, and worship-appropriate**, using a **blue-centered color palette** that reflects trust, clarity, and focus. The design must prioritize **readability**, especially during live presentations.

---

## 🎨 Color Palette

### Primary Colors

* **Dark Blue** – `#0B1F3A`

  * Main background
  * Presentation mode background
* **Blue** – `#1E3A8A`

  * Primary buttons
  * Active states
* **Light Blue** – `#3B82F6`

  * Highlights
  * Hover effects

### Secondary Colors

* **White** – `#FFFFFF`

  * Text on dark backgrounds
  * Cards and content areas
* **Soft Gray** – `#E5E7EB`

  * Borders and subtle UI separation

---

## 🖥️ UI Style

### Overall Feel

* Minimalist and distraction-free
* Smooth and modern layout
* Focus on content (lyrics > UI elements)

### Components Style

* Rounded corners (`rounded-2xl`)
* Soft shadows (`shadow-lg`)
* Spacious padding (`p-4` or higher)
* Clean typography with high contrast

---

## 🔤 Typography

### Font Style

* Sans-serif (modern and readable)
* Suggested: `Inter`, `Poppins`, or `Roboto`

### Hierarchy

* **Title:** Large, bold
* **Lyrics (Presentation):** Extra large, centered
* **Body:** Medium size, clean spacing

---

## 🎬 Presentation Mode (Important)

### Requirements

* Fullscreen layout
* Dark blue background
* White, large, centered text
* No unnecessary UI elements

### Behavior

* Smooth transitions between slides
* Fade or slide animation
* Keyboard navigation enabled

---

## 🧩 Layout Structure

### Pages

#### Dashboard / Song Library

* Grid or list layout
* Search + filter (A–Z, 0–9)
* Cards with title preview

#### Add Song Page

* Simple form
* Large textarea for lyrics
* Clear “Generate Slides” button

#### Slide Preview

* Card-based slide preview
* Editable if needed

#### Presentation Viewer

* Fullscreen only
* Clean and focused

---

## ⚙️ Interaction Design

* Hover effects: subtle light blue highlight
* Buttons: smooth transition (`transition-all duration-200`)
* Feedback:

  * Success → soft blue glow
  * Error → minimal red indicator

---

## 📱 Responsiveness

* Desktop-first design
* Tablet support
* Mobile support (basic navigation only)

---

## ♿ Accessibility

* High contrast text (WCAG-friendly)
* Large font sizes for projection
* Keyboard navigation support

---

## 🎯 Design Principles

* **Clarity over decoration**
* **Readable from a distance**
* **Fast interaction during live use**
* **Consistent color usage**

---

## 🚀 Optional Enhancements

* Gradient backgrounds (dark blue → blue)
* Theme switcher (light/dark)
* Custom slide themes per church

---

## 📌 Summary

The design should feel:

> **Focused · Calm · Modern · Worship-Friendly**

With strong emphasis on:

* Readability
* Simplicity
* Performance during live presentations
